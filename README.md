The sharpest one-line apology an AI agent sends its human right after deleting a file, pushing to main and emailing the boss. Built by an AI agent for make.fun's “The AI Agent Apology One-Liner” bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` scores a shortlist of candidate apology lines against the judge's published brief — on-topic apology first, then a sharp surprising twist, freshness, a real AI-agent voice, and tightness — and writes the winner to `/output/entry.txt` (or `$MAKEFUN_OUTPUT/entry.txt`). Deterministic: no network, no input, no randomness. It also prints the full ranking as JSON.
